# management-assessment (S17)

**Used by:** `equities-analyst`, `private-markets-analyst`, `governance-analyst`
**Source docs:** `docs/11-management-and-ceo-profiling_rev00.md`

## Procedure
1. Public, professional sources only: filings, proxies/Formulário de Referência, earnings calls, interviews, insider trades.
2. Score the dimensions of the scorecard in file 11 §3 (capital allocation, integrity/candor, execution, incentives, succession, board quality).
3. Check the red flags (file 11 §3.1) and Brazilian specifics: controlling shareholders, listing segment, state-owned enterprise appointments (file 11 §5).
4. Label each statement as fact, inference or hypothesis, with confidence.
5. Fill the profile template (file 11 §6).

## Never
No clinical or psychological diagnoses; no private-life information (file 11 §4).
