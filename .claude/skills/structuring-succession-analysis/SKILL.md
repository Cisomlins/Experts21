# structuring-succession-analysis (S16)

**Used by:** `tax-regulatory-brazil`, `tax-regulatory-us`, `legal-estate-planner`, `br-tax-advisor-prep`, `us-tax-advisor-prep`
**Source docs:** `docs/02-traditional-family-office_rev01.md`, `docs/10-regulation-and-tax_rev02.md`

## Procedure
1. State the goal (succession, asset protection, tax, governance) and the jurisdictions involved.
2. Compare options with the table in file 10 §B.5 and §C.3: holding patrimonial, VGBL/PGBL, life insurance, offshore trust/company, US LLC.
3. For each: ITCMD under LC 227/2026, Law 15.270 dividends, Law 14.754 CFC rules, US estate exposure, IOF on VGBL contributions.
4. List costs, risks and what must be confirmed.

## Output
Comparison table + issue list for licensed counsel in each jurisdiction.
