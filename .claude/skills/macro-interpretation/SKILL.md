# macro-interpretation (S10)

**Used by:** `fixed-income-analyst`, `commodities-energy-analyst`, `fx-strategist`, `macro-economist`
**Source docs:** `docs/08-economy-and-macro_rev01.md`

## Procedure
1. Place the economy in the four-quadrant growth/inflation regime (file 08 §1.2).
2. Check the latest releases against consensus (US: CPI/PCE, payrolls, ISM, GDP; Brazil: IPCA, Focus survey, IBC-Br, fiscal results). Use primary sources (file 08 §2).
3. Read policy: Fed funds path and dot plot; Selic path and Copom guidance; real rates.
4. Link to assets with the channels in file 08 §4 (curve, spreads, dollar cycle, commodities, China).
5. Separate the consensus view from your own view.

## Output
Use the Weekly Macro Brief template (file 08 §6.2). Every figure dated.
