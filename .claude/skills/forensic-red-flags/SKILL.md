# forensic-red-flags (S18)

**Used by:** `equities-analyst`, `governance-analyst`, `forensic-analyst`
**Source docs:** `docs/11-management-and-ceo-profiling_rev00.md`

## Procedure
1. Compute accrual and cash-conversion ratios over 3–5 years.
2. Compute the Beneish M-score where data allow; note that published cut-offs differ (−1.78 or −2.22; file 11).
3. Check auditor changes, CFO turnover, restatements, related-party transactions, aggressive guidance.
4. Rate red / amber / green with the evidence for each.

## Never
Present suspicion as suspicion, never as fact; never accuse anyone publicly.
